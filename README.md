# ⚔️ OPR Battle Tracker

Un outil simple et autonome pour suivre vos batailles dans les jeux **OnePageRules** (Grimdark Future, Age of Fantasy, Warfleet FTL, etc.).

## 🚀 Fonctionnalités

- **Suivi complet** : Scénario, armées, points d'armée, pseudos des adversaires, scores et notes.
- **Multi-jeux** : Supporte tous les systèmes OPR officiels et les règles maison.
- **Contexte** : Gestion des batailles uniques, campagnes et tournois.
- **Export flexible** :
  - 📄 **PDF** : Génération d'un historique propre et imprimable.
  - 📊 **CSV** : Export pour Excel/Numbers pour faire vos statistiques.
  - 💾 **JSON** : Sauvegarde et restauration complète de vos données.
- **100% Privé** : Toutes les données sont stockées localement dans votre navigateur. Rien n'est envoyé sur un serveur.
- **Sans installation** : Un simple fichier HTML à ouvrir dans n'importe quel navigateur.

## 🛠️ Comment l'utiliser ?

1. Téléchargez le fichier `index.html`.
2. Ouvrez-le avec votre navigateur web préféré (Chrome, Firefox, Edge, Safari).
3. Commencez à enregistrer vos parties !
4. Pensez à utiliser le bouton **JSON (Sauvegarde)** régulièrement pour exporter vos données.

## 📦 Installation (Hébergement personnel)

Si vous souhaitez héberger cet outil vous-même :

1. Clonez ce dépôt.
2. Ouvrez simplement le fichier `index.html` localement.
3. Ou hébergez-le sur GitHub Pages, Netlify, ou n'importe quel serveur statique.
